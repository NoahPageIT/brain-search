# 🧠 Brain Search

Local **semantic search + RAG chat** over your Obsidian second brain. Embeddings run **on-device** (transformers.js / all-MiniLM-L6-v2) and the optional chat uses a **local Ollama model** - so the whole thing is private and costs nothing.

## Two modes
- **🔍 Search** - finds notes by *meaning*, not just keywords (works immediately, no LLM)
- **💬 Ask (AI)** - answers questions using your notes as context, generated by a local Ollama model

## Setup
```bash
# 1. Build the index over your vault (re-run whenever notes change)
NODE_OPTIONS=--use-system-ca node index.js

# 2. Start the server
NODE_OPTIONS=--use-system-ca node server.js   # → http://localhost:3005
```

`--use-system-ca` makes Node trust the OS certificate store (needed on machines behind an SSL-inspecting proxy, so the model can download on first run).

### Enable AI chat (optional, free)
1. Install [Ollama](https://ollama.com/download)
2. Pull a small model: `ollama pull llama3.2`
3. Use the **Ask (AI)** tab - answers are generated locally and cited to your notes.

Set a different model with `OLLAMA_MODEL=<name>`.

## How it works
Notes are chunked and embedded into 384-dim vectors stored in `index.json`. A query is embedded the same way; results rank by cosine similarity. For chat, the top chunks become context for the local LLM (retrieval-augmented generation). Your note content never leaves the machine.

*`index.json` is git-ignored - it contains your note content.*
